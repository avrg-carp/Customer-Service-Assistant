# Ниша: ИИ-помощник по комплаенсу и регуляторике

Дата: 2026-10-20. Пометка **(из знаний)** — не проверялось поиском. Поиск по этой нише дал мало, часть источников старая (2018–2021).

## 1. Задача

Банк работает под давлением регуляторики: 115-ФЗ (ПОД/ФТ), 152-ФЗ, 161-ФЗ, 395-1, положения и указания ЦБ, требования по ИБ, санкции, валютный контроль. Нормы часто меняются. По материалам Контура, за нарушения 115-ФЗ грозят штраф до 1 млн ₽, приостановка деятельности и отзыв лицензии. [Контур.Фокус](https://focus.kontur.ru/site/industry-compliance/bank), [Контур](https://kontur.ru/articles/5934)

Регулярные задачи:

1. Ответить «можно ли и как» со ссылкой на пункт и редакцию на дату.
2. Отследить изменения: что вышло, кого касается.
3. Сопоставить внешние нормы с внутренними политиками и найти расхождения.
4. Подготовить ответ на запрос регулятора или обоснование решения по клиенту.
5. Сопроводить 115-ФЗ: основания отказа, формулировки, перечень документов.

## 2. Пользователи

| Пользователь | Типовой вопрос | Ценность |
|---|---|---|
| Комплаенс-офицер, ПОД/ФТ | Основание отказа, перечень документов | Скорость, единообразие |
| Юрист банка | Позиция по норме, черновик заключения | Поиск и подготовка |
| Операционист, менеджер отделения | Можно ли принять документ | Меньше эскалаций |
| Риск-менеджер, ИБ | Соответствие процесса требованиям | Матрица соответствия |
| Методолог | Какие внутренние документы затронуты новым актом | Анализ влияния |

## 3. Решения в РФ

Подтверждено поиском:

- **КонсультантПлюс** — ИИ-помощник, отвечает только по документам системы (кодексы, письма Минфина и ФНС, решения), готовит заключения, проверяет договоры. [ppt.ru](https://ppt.ru/news/press/poprobuyte-ii-pomoshchnik-ot-konsultantplyus), [consultant.ru](https://www.consultant.ru/about/iip/)
- **Гарант** — по вторичным источникам, с февраля 2026 «Правовой поиск» направляет ответы модели в базу законодательства; собственные ИИ-функции не подтверждены. [Habr](https://habr.com/ru/articles/1001504)
- **Яндекс «Нейроюрист»** — массовый, для общего права, 20 бесплатных запросов в месяц. [comss.ru](https://www.comss.ru/page.php?id=18591)
- **Контур.Фокус (комплаенс), Контур.Призма** — проверка контрагентов по 115-ФЗ, анкетирование, риски, реакция на изменения нормативов. [Фокус](https://focus.kontur.ru/site/115-fz), [Призма](https://kontur.ru/press/news/company/2018/8/6337)
- **Платформа ЦБ «Знай своего клиента»** — распределяет клиентов по группам риска; решение остаётся за банком. [MOS Digitals](https://mosdigitals.ru/blog/regtech-kak-tehnologii-avtomatizaczii-pomogayut-biznesu-soblyudat-regulyatornye-trebovaniya)

(из знаний): системы ПОД/ФТ и мониторинга операций (Диасофт, R-Style Softlab, BSS), Интерфакс (СПАРК), внутренние юридические ассистенты крупных банков на базе GigaChat и собственных моделей.

Публичных готовых продуктов «ИИ-помощник по регуляторике со ссылками на внутренние политики банка» почти нет.

## 4. Зарубежные решения (ориентир)

Поиск подтвердил общий контекст: по рейтингу RegTech100 вендоры встраивают ИИ для предвидения регуляторных изменений; 63% финансовых организаций ожидают рост расходов на RegTech в 2026. Типовые функции: мониторинг источников, ИИ-поиск, выявление пробелов, привязка норм к внутренним политикам. [FinTech Global](https://fintech.global/2025/12/10/ninth-annual-regtech100-reveals-the-regtechs-to-watch-in-2026/), [Vixio](https://www.vixio.com/webinars-and-videos/global-state-of-regtech-industry-2026)

(из знаний): Wolters Kluwer OneSumX, Thomson Reuters Regulatory Intelligence, CUBE, Compliance.ai, Ascent, Moody's, LexisNexis Risk. Для РФ недоступны.

## 5. Пробелы рынка

1. Внешние и внутренние нормы в одном ответе.
2. Закрытый контур для вопросов с данными клиентов и сведениями по подозрительным операциям.
3. Редакция на дату («как было на дату операции»).
4. Анализ влияния изменений на внутренние документы.
5. Прозрачность решения по 115-ФЗ: ссылка на пункт, след для проверки регулятором.

## 6. Модули

| Модуль | Что делает | Опора в проекте |
|---|---|---|
| Q&A по нормам | Ответ со ссылкой на пункт и редакцию | RAG, цитаты `[n]`, проверка ссылок |
| Версионность и даты | Ответ «на дату», пометка утративших силу | `valid_from/valid_to`, `version` |
| Внутренние политики | Сопоставление нормы с регламентом банка | Общий корпус, роли |
| Мониторинг изменений | Поток актов ЦБ/Минфина/законов, краткий разбор | Инкрементальная индексация |
| Анализ влияния | Список затронутых внутренних документов | Новый модуль поверх поиска |
| Карточка обоснования | Черновик обоснования или заключения со ссылками | Генерация и шаблоны |
| Журнал и аудит | Кто что спросил, какие источники | Логи без ПДн |

## 7. Источники данных

- Для конкурса: сайт ЦБ (указания, положения, письма, FAQ), pravo.gov.ru, Росфинмониторинг (обзоры, типологии, методические рекомендации), Минфин, законы и кодексы.
- Коммерческие базы (КонсультантПлюс, Гарант) парсить нельзя — нарушение лицензий. Условия каждого источника проверять.
- Реальный банк: внутренние политики, правила ПВК, приказы, инструкции; роли и фильтры доступа.

## 8. Риски

1. Юридическая ответственность за ответ: отказ при низкой уверенности, обязательные ссылки, явное «решение принимает сотрудник».
2. Конфиденциальность 115-ФЗ: нельзя раскрывать клиенту факт передачи сведений в Росфинмониторинг — закрепить ролями и фильтрами.
3. Парсинг юридических текстов: нумерация статей и пунктов, «в редакции от…», приложения-таблицы.
4. Регулирование ИИ: Банк России готовит кодекс этики и предложения по высокорисковым сферам; статус проверять. [дорожная карта](https://legalacts.ru/doc/plan-meroprijatii-dorozhnaja-karta-po-realizatsii-osnovnykh-napravlenii-razvitija_2/)
5. Правовые системы могут добавить внутренние документы клиента; защита — закрытый контур, версионность, интеграция с процессами банка.
6. Часть источников устарела — проверять статус по официальным сайтам.

## 9. Позиционирование

> Ассистент по регуляторике, который знает и внешние нормы, и внутренние политики банка, отвечает со ссылкой на пункт и редакцию на дату, работает в закрытом контуре и оставляет след для проверки.
