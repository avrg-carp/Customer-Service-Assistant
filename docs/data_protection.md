# Защита данных и on-prem

- единый docker-compose, в on-prem режиме нет внешних вызовов
- маскирование ПДн (ФИО, телефоны, карты, паспорта) перед LLM
- фильтрация по ролям на уровне запроса к Qdrant, а не в UI
- документы — данные, не инструкции (защита от prompt injection)
- логи без ПДн, с сроком хранения
- JWT + 3 демо-роли: оператор, менеджер, руководитель
